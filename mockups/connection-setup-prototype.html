Connection setup

Run checks from Ubuntu. That is where HarnessKit is running; SSH settings in your Windows browser’s account are not used.

Complete these steps in order

Need an SSH key?
  1. In Ubuntu, check for an existing key first. If needed, run ssh-keygen -t ed25519 and choose an unused filename. Keep the private key private.
  2. Add only the matching public .pub key to the destination account’s ~/.ssh/authorized_keys, using that machine’s terminal or an existing password-authenticated session.
  3. Sign in once from Ubuntu and verify the host fingerprint. Load an encrypted key into an SSH agent available to HarnessKit.
  4. Check ssh -o BatchMode=yes user@host python3 --version with your account, host and optional -p PORT. It must complete without a prompt. Start HarnessKit from that same authenticated environment.
What happens after setup?

Test connection checks access. Then review detected folders, choose what to sync and select the direction. Connecting alone should not enable synchronization. Keep HarnessKit running for automatic sync.
